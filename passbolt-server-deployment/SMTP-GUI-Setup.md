# E-Mail in Passbolt GUI einstellen (AD-Credentials)

Administration > E-Mail-Server:

| Einstellung | Wert |
|-------------|------|
| Provider | Andere |
| Authentifizierung | Benutzername und Passwort |
| Benutzername | Dein AD-User (z.B. user@<COMPANY-DOMAIN>) |
| Passwort | Dein AD-Passwort |
| SMTP-Host | mail.<COMPANY-DOMAIN> |
| Port | 587 |
| TLS verwenden | Ja |
| Absender | Passbolt / passbolt@<COMPANY-DOMAIN> |

Speichern, dann Test-E-Mail senden.
